# UI Polishing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pixel font with self-hosted Inter and IM Fell English SC, restyle every screen, the HUD and the admin page in "Leather & brass", and add the cooldown ring, effect symbols and a Settings screen.

**Architecture:** The fonts are vendored `woff2` files in `client/public/fonts/` with `@font-face` rules in `style.css`, preloaded by `index.html` and `admin.html`; `client/src/fonts.ts` holds the font-family names for Phaser and awaits the faces before Phaser starts. The look is CSS on the existing class names (tokens on `:root`). New logic sits in small, tested modules: `ui/effectIcons.ts` (symbols for HTML and Phaser), `ui/cooldown.ts` (ring state), `ui/settings.ts` (the Settings view), `game/keycap.ts` (the in-world E cap).

**Tech Stack:** TypeScript 5.9, Phaser 3.90, Vite 7, Vitest 3 (jsdom), plain CSS; playwright-core smoke test.

**Spec:** [docs/superpowers/specs/2026-10-22-ui-polish-design.md](../specs/2026-10-22-ui-polish-design.md), with the mockups [ui-font-trial.html](../specs/2026-10-22-ui-polish/ui-font-trial.html) (screens: option D + "Leather & brass") and [ui-ingame-trial.html](../specs/2026-10-22-ui-polish/ui-ingame-trial.html) (in the run: look "New"). Read both before any task; exact CSS values come from the mockups' `[data-style="brass"]` and `.stage.new` rules unless this plan or the spec says otherwise.

## Global Constraints

- Branch `feature/ui-polish`. All commands from the repo root `TinyAdventurers/` unless shown. Node comes through nvm: run npm/npx/node as `bash -lic '…'`.
- Fonts: **Inter** for all text (weights 400–800, variable), **IM Fell English SC** (400) only for headings, never below ~16 px. Press Start 2P and JetBrains Mono are removed. No request to `fonts.googleapis.com` / `fonts.gstatic.com` remains; no other CDN.
- Font family strings (use these exact values everywhere): text `'Inter', system-ui, sans-serif`; heading `'IM Fell English SC', Georgia, serif`.
- Palette tokens on `:root` (spec "Palette"): `--bg #0f090e`, `--panel #221620`, `--panel-edge #5a3a4a` (unchanged), `--text #f0e6d8` (unchanged), `--muted #b3a3a8`, `--gold #e8c040` (unchanged), `--red #e05050`, `--green #5cc870`, new `--faint #847379`, `--well #150d13`, `--gold-deep #9a7420`, `--gold-ink #2a1806`, `--edge-soft #3d2834`. Add `--font-text` and `--font-head` with the strings above; `--font` is removed.
- Sizes: body 15 px, small 13 px, smallest 11.5 px; HUD 13 px; nothing in the HTML UI below 11 px. Digits that stand in columns or change in place use `font-variant-numeric: tabular-nums`.
- Buttons: padding `5px 10px`, `line-height: 1.3`, radius 6 px. Tabs: padding `7px 12px`. Fields and selects: padding `10px 12px`, radius 8 px. Disabled: opacity 0.4. Every control has a visible gold focus ring.
- No game rule or protocol change. No layout restructure of the screens.
- Every task ends green: `bash -lic 'cd client && npx vitest run && npx tsc --noEmit'`. Tasks that change looks also run the smoke test and look at its shots (see "Visual check").
- Commit messages: `UI polish: <what>`, ending with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` after a blank line.

**Visual check** (used by tasks 2–5, 7, 9, 10): `docker compose up -d --build`, then `bash -lic 'cd tools/e2e && BROWSER=/usr/bin/brave-browser node smoke.mjs http://localhost:8080/ "" shots Wizard,Barbarian'`. ## Review Focus

1. **Phaser text created before the fonts load** keeps a fallback face for its lifetime: name tags of heroes present at run start must render in Inter on a cold cache (Task 1's `loadFonts` gate, test in Task 1).
2. **Long text in the new sizes:** a 20-letter character name (the coming name rule) in the roster card, the hub top bar, the party list, the name tag and the end table must not overflow or overlap at 1280 × 720 (Task 2/3/4 visual checks use a long name; Task 7 tests tag-symbol placement for a long name).

4. **Effects arriving and leaving every snapshot:** the HUD symbol rows and the name-tag symbols must not rebuild every frame or leak Phaser images (Task 8 test on rebuild keys, Task 7 test on pooling).
5. **Settings out of sync with keys:** pressing `L`, `Shift+L` or `F3` while the Settings view is open must update its checkboxes, and the rules log's saved prefs must survive (Task 9 tests).

```ts
export interface SlotView { fill: number; ready: boolean; label: string }   // fill 0..1 clockwise from the top
export function slotView(cd: number, max: number): SlotView;
// cd <= 0 → { fill: 1, ready: true, label: '' }; else fill = clamp(1 - cd / max, 0, 1), label = cd.toFixed(1)
export class CooldownTracker { update(cd: number): { view: SlotView; flash: boolean } }
// keeps max and the last cd exactly like hud.ts today (max := cd when cd rises by more than 0.01);
// flash is true only on the frame the slot turns ready after having been cooling (not on the first update).
```
