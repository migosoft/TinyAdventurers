# Effect System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every creature can carry timed status effects (Blind, Sleep, Petrified, Slowed, Accelerated) that change its stats and can forbid moving, acting or turning. The lich casts the first three, and the client shows all five.

**Architecture:**
- **Data:** `defs/effects.rs` holds the effect data (kinds, mods, flags, per-creature responses).
- **Runtime:** `run/effects.rs` holds the timers (`Effects` on every `Player` and `Monster`), the `Run` API (`apply_effect`, `remove_effect`, `has_effect`), ticking and the teammate wake-up.
- **Stat reads:** every existing read of speed, sight, resistances and knockback goes through `Effects` helpers.
- **Hits:** effects ride on hits through `Damage::on_hit`.
- **Wire:** the snapshot carries a `u16` effects bitmask per entity and the own hero's timers, resolved speed factor and vision.
- **Client:** it predicts with them, draws one data-driven visual per effect (`game/status.ts`) and shows HUD icons.

**Tech Stack:** Rust server (tokio, rmp-serde, ts-rs, rand_chacha), TypeScript + Phaser 3.90.0 client (vitest).

**Spec:** [docs/superpowers/specs/2026-10-15-effects-design.md](../specs/2026-10-15-effects-design.md) (approved by the user 2026-10-15).

## Global Constraints
- **Effect ids (wire bits):** `Blind = 0`, `Sleep = 1`, `Petrified = 2`, `Slowed = 3`, `Accelerated = 4`. Bit = `1 << id` in a `u16`.
- **Starting values:**
  - Blind 3 s: `Vision Set 0`, `Darkvision Set 0`.
  - Sleep 4 s: `Vision Mul 0.15`; `no_move`, `no_act`, `prone`, `wakes_on_use`.
  - Petrified 3 s: `Resist(Physical) Add 0.75`, every other type `Add 0.5`, `KnockTaken Mul 0.4`; `no_move`, `no_act`, `no_turn`.
  - Slowed 3 s: `MoveSpeed Mul 0.5`.
  - Accelerated 3 s (positive): `MoveSpeed Mul 1.5`.
- **Resolution:** base, then every `Add`, then every `Mul`, then the lowest `Set` wins. An effect never raises a resistance above 1.0 (immunity) unless the base already is above it, so petrified undead are not healed by poison.
- **Responses:** `Immune` / `Reduced` (`EFFECT_REDUCED = 0.5` × duration) / `Full` (default).
  - Lich: Sleep and Blind immune, Petrified reduced.
  - Dragon: Sleep immune, the rest reduced.
  - Demon: Sleep immune, the rest full.
  - Everyone else: full.
- **Stacking:** refresh, `left = max(left, new)`.
- **Sleep:** damage never wakes. A living teammate's E within reach (`gap = dist − 2 × PLAYER_RADIUS ≤ USE_REACH`) wakes, and waking beats objects. The sleeper's own E is blocked by `no_act`.
- **Damage resistance and effect response are independent.** A hit with `amount == 0.0` and an `on_hit` applies only the effect (no damage number, no hurt flash).
- **`chance >= 1.0` never draws from the rng,** so runs that only use certain effects stay deterministic and the fingerprints stay unchanged.
- **Lich spells:**
  - Blinding curse: wind-up 0.6 s, orb 6 magical damage + Blind 3 s, cooldown 10 s, first at 4 s.
  - Sleep mist: wind-up 0.8 s, orb 0 damage + Sleep 4 s, cooldown 14 s, first at 7 s.
  - Stone gaze: wind-up 1.0 s, a beam locked on one hero, then a 0-damage Petrified 3 s hit if the lich still `sees` them; cooldown 18 s, first at 9 s.
  - The spells are one `SPELLS` table.
- **Protocol:**
  - `EntSnap` and `EntW` gain a trailing `u16` effects field.
  - `SelfState` and `SelfW` gain, after `darkvision` and in this order: `vision: f32` (viewed hero's tiles), `effects: Vec<(u8, f32)>`, `speed_mul: f32`, `no_act: bool`.
  - New event `Effect { id, kind, on }` (code 13).
  - `ClientMsg::DebugEffect { kind: u8 }`, honoured only when `debug::allowed()`.
- **Rename** `asleep` → `dormant` and `FLAG.ASLEEP` → `FLAG.DORMANT`. No behaviour change, fingerprints identical.
- **Fingerprints:** only the lich hall value of `simulation_is_unchanged_after_waking_the_boss` may change (the new spells). Re-record it with a dated comment that names the cause. Every other fingerprint must stay as it is.
- **Desktop only;** no new art (drawn glyphs and tints). Debug key **F8**.

//! `run/effects.rs`. Adding an effect: a new `EffectKind` (next id), its

use super::damage::DamageType;

/// Open set. The id is the effect's bit in the snapshot's `u16` bitmask.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize)]
#[repr(u8)]
pub enum EffectKind {
    Blind = 0,
    Sleep = 1,
    Petrified = 2,
    Slowed = 3,
    Accelerated = 4,
}

impl EffectKind {
    pub const COUNT: usize = 5;
    pub const ALL: [EffectKind; EffectKind::COUNT] = [EffectKind::Blind, EffectKind::Sleep, EffectKind::Petrified, EffectKind::Slowed, EffectKind::Accelerated];
    pub fn bit(self) -> u16 {
        1 << self as u8
    }
    pub fn from_u8(v: u8) -> Option<EffectKind> {
        EffectKind::ALL.get(v as usize).copied()
    }
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum Stat {
    /// Factor on the creature's move speed (base 1).
    MoveSpeed,
    /// Tiles.
    Vision,
    /// Share of vision.
    Darkvision,
    Resist(DamageType),
    /// Factor on knockback distances taken (base 1).
    KnockTaken,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum Op {
    Add,
    Mul,
    Set,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct StatMod {
    pub stat: Stat,
    pub op: Op,
    pub value: f64,
}

const fn m(stat: Stat, op: Op, value: f64) -> StatMod {
    StatMod { stat, op, value }
}

#[derive(Debug, Clone, Copy)]
pub struct EffectDef {
    /// Default seconds (a source may pass its own).
    pub duration: f64,
    /// Good for the creature (HUD frame green instead of red).
    pub positive: bool,
    pub mods: &'static [StatMod],
    pub no_move: bool,
    pub no_act: bool,
    pub no_turn: bool,
    /// Lying down (drawn rotated on the client).
    pub prone: bool,
    /// Damage ends it (none yet; for a future monster sleep).
    pub wakes_on_damage: bool,
    /// A teammate's E next to the creature ends it.
    pub wakes_on_use: bool,
}

const NONE: EffectDef = EffectDef { duration: 3.0, positive: false, mods: &[], no_move: false, no_act: false, no_turn: false, prone: false, wakes_on_damage: false, wakes_on_use: false };

pub fn def(k: EffectKind) -> EffectDef {
    use DamageType::*;
    use Op::*;
    use Stat::*;
    match k {
        EffectKind::Blind => EffectDef { mods: &[m(Vision, Set, 0.0), m(Darkvision, Set, 0.0)], ..NONE },
        EffectKind::Sleep => EffectDef { duration: 4.0, mods: &[m(Vision, Mul, 0.15)], no_move: true, no_act: true, prone: true, wakes_on_use: true, ..NONE },
        EffectKind::Petrified => EffectDef {
            mods: &[
                m(Resist(Physical), Add, 0.75),
                m(Resist(Cold), Add, 0.5),
                m(Resist(Heat), Add, 0.5),
                m(Resist(Magical), Add, 0.5),
                m(Resist(Poison), Add, 0.5),
                m(KnockTaken, Mul, 0.4),
            ],
            no_move: true,
            no_act: true,
            no_turn: true,
            ..NONE
        },
        EffectKind::Slowed => EffectDef { mods: &[m(MoveSpeed, Mul, 0.5)], ..NONE },
        EffectKind::Accelerated => EffectDef { positive: true, mods: &[m(MoveSpeed, Mul, 1.5)], ..NONE },
    }
}

/// Duration factor for a `Reduced` response.
pub const EFFECT_REDUCED: f64 = 0.5;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum EffectResponse {
    Immune,
    Reduced,
    Full,
}

/// How a creature takes each effect; `Full` unless listed.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct EffectResponses([EffectResponse; EffectKind::COUNT]);

impl EffectResponses {
    pub const FULL: EffectResponses = EffectResponses([EffectResponse::Full; EffectKind::COUNT]);
    pub fn of(parts: &[(EffectKind, EffectResponse)]) -> Self {
        let mut r = Self::FULL;
        for &(k, v) in parts {
            r.0[k as usize] = v;
        }
        r
    }
    pub fn get(&self, k: EffectKind) -> EffectResponse {
        self.0[k as usize]
    }
}

/// An effect a hit applies after its damage (see `Damage::on_hit`).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct OnHit {
    pub kind: EffectKind,
    pub secs: f64,
    /// 0..=1; 1 or more applies without a roll.
    pub chance: f64,
}

/// `base` with every mod on `stat` of the active `kinds`: all `Add`s, then
/// all `Mul`s, then the lowest `Set`. An effect never lifts a resistance
/// above 1 (immunity) unless the base already is.
pub fn resolve_stat(base: f64, stat: Stat, kinds: &[EffectKind]) -> f64 {
    let mods = || kinds.iter().flat_map(|&k| def(k).mods.iter()).filter(move |md| md.stat == stat);
    let mut v = base + mods().filter(|md| md.op == Op::Add).map(|md| md.value).sum::<f64>();
    v *= mods().filter(|md| md.op == Op::Mul).map(|md| md.value).product::<f64>();
    if let Some(set) = mods().filter(|md| md.op == Op::Set).map(|md| md.value).reduce(f64::min) {
        v = set;
    }
    if matches!(stat, Stat::Resist(_)) && v > base {
        v = v.min(base.max(1.0));
    }
    v
}

    pub left: f64,
}

/// The effects on one creature (a handful at most) and its stats through them.
#[derive(Debug, Clone, Default)]
pub struct Effects(Vec<ActiveEffect>);

impl Effects {
    pub fn list(&self) -> &[ActiveEffect] {
        &self.0
    }
    pub fn has(&self, k: EffectKind) -> bool {
        self.0.iter().any(|a| a.kind == k)
    }
    pub fn kinds(&self) -> Vec<EffectKind> {
        self.0.iter().map(|a| a.kind).collect()
    }
    pub fn bits(&self) -> u16 {
        self.0.iter().fold(0, |b, a| b | a.kind.bit())
    }
    /// Refresh: the longer of the remaining and the new time. True when newly added.
    pub fn add(&mut self, k: EffectKind, secs: f64) -> bool {
        if let Some(a) = self.0.iter_mut().find(|a| a.kind == k) {
            a.left = a.left.max(secs);
            return false;
        }
        self.0.push(ActiveEffect { kind: k, left: secs });
        true
    }
    pub fn remove(&mut self, k: EffectKind) -> bool {
        let n = self.0.len();
        self.0.retain(|a| a.kind != k);
        self.0.len() != n
    }
    /// Counts down; returns the kinds that ran out (removed).
    fn tick(&mut self, dt: f64) -> Vec<EffectKind> {
        for a in &mut self.0 {
            a.left -= dt;
        }
        let gone: Vec<EffectKind> = self.0.iter().filter(|a| a.left <= 0.0).map(|a| a.kind).collect();
        self.0.retain(|a| a.left > 0.0);
        gone
    }
    fn take_all(&mut self) -> Vec<EffectKind> {
        std::mem::take(&mut self.0).into_iter().map(|a| a.kind).collect()
    }
    fn any(&self, f: impl Fn(&crate::defs::effects::EffectDef) -> bool) -> bool {
        self.0.iter().any(|a| f(&def(a.kind)))
    }
    pub fn no_move(&self) -> bool {
        self.any(|d| d.no_move)
    }
    pub fn no_act(&self) -> bool {
        self.any(|d| d.no_act)
    }
    pub fn no_turn(&self) -> bool {
        self.any(|d| d.no_turn)
    }
    /// Factor on the creature's move speed; 0 while it cannot move.
    pub fn speed_mul(&self) -> f64 {
        if self.no_move() {
            return 0.0;
        }
        resolve_stat(1.0, Stat::MoveSpeed, &self.kinds())
    }
    pub fn sight(&self, base: Sight) -> Sight {
        let k = self.kinds();
        Sight { vision: resolve_stat(base.vision, Stat::Vision, &k), darkvision: resolve_stat(base.darkvision, Stat::Darkvision, &k) }
    }
    pub fn res(&self, base: Resistances) -> Resistances {
        let k = self.kinds();
        let mut r = base;
        for t in DamageType::ALL {
            r.set(t, resolve_stat(base.get(t), Stat::Resist(t), &k));
        }
        r
    }
    pub fn knock_taken(&self) -> f64 {
        resolve_stat(1.0, Stat::KnockTaken, &self.kinds())
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Creature {
    Player(usize),
    Monster(usize),

impl Run {
    fn creature(&mut self, c: Creature) -> Option<(&mut Effects, u32, crate::math::Vec2, bool)> {
        match c {
            Creature::Player(i) => {
                let p = self.players.get_mut(i)?;
                let ok = p.alive && p.sinking.is_none();
                Some((&mut p.effects, p.id, p.pos(), ok))
            }
            Creature::Monster(i) => {
                let m = self.monsters.get_mut(i)?;
                let ok = m.alive && m.sinking.is_none();
                Some((&mut m.effects, m.id, m.pos, ok))
            }
        }
    }

    fn effect_event(&mut self, c: Creature, id: u32, pos: crate::math::Vec2, k: EffectKind, on: bool) {
        let ev = Ev::Effect { id, kind: k as u8, on };
        match c {
            Creature::Player(_) => self.event_on_hero(ev, pos),
            Creature::Monster(_) => self.event(ev, Some(pos)),
        }
    }

    /// Puts `kind` on a creature for `secs` (default: its def's duration),
    /// shortened or refused by the creature's response. Dead or sinking
    /// creatures take nothing. True when the effect is on afterwards.
    pub fn apply_effect(&mut self, c: Creature, kind: EffectKind, secs: Option<f64>) -> bool {
        let response = match c {
            Creature::Player(_) => EffectResponse::Full,
            Creature::Monster(i) => self.monsters.get(i).map_or(EffectResponse::Immune, |m| m.responses.get(kind)),
        };
        let mut secs = secs.unwrap_or(def(kind).duration);
        match response {
            EffectResponse::Immune => return false,
            EffectResponse::Reduced => secs *= EFFECT_REDUCED,
            EffectResponse::Full => {}
        }
        let Some((fx, id, pos, ok)) = self.creature(c) else { return false };
        if !ok || secs <= 0.0 {
            return false;
        }
        if fx.add(kind, secs) {
            self.effect_event(c, id, pos, kind, true);
        }
        true
    }

    pub fn remove_effect(&mut self, c: Creature, kind: EffectKind) -> bool {
        let Some((fx, id, pos, _)) = self.creature(c) else { return false };
        let removed = fx.remove(kind);
        if removed {
            self.effect_event(c, id, pos, kind, false);
        }
        removed
    }

    pub fn has_effect(&self, c: Creature, kind: EffectKind) -> bool {
        match c {
            Creature::Player(i) => self.players.get(i).is_some_and(|p| p.effects.has(kind)),
            Creature::Monster(i) => self.monsters.get(i).is_some_and(|m| m.effects.has(kind)),
        }
    }

    /// Once per step: timers count down; the dead and sinking lose everything.
    pub fn tick_effects(&mut self) {
        let n = (self.players.len(), self.monsters.len());
        let all = (0..n.0).map(Creature::Player).chain((0..n.1).map(Creature::Monster));
        for c in all.collect::<Vec<_>>() {
            let Some((fx, id, pos, ok)) = self.creature(c) else { continue };
            if fx.list().is_empty() {
                continue;
            }
            let gone = if ok { fx.tick(DT) } else { fx.take_all() };
            for k in gone {
                self.effect_event(c, id, pos, k, false);
            }
        }
    }
}
